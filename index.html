3.3 AI Smart Match Engine

Algorithm Logic:

The match engine calculates a compatibility score (0–100%) between users based on weighted signals:

Signal Weight Description
Industry Match 35% Same or related industry category
Location Proximity 20% City → State → Country scoring
Services Overlap 20% Tags match between what user needs vs offers
Activity Score 15% Recent login, posts, responses
Trust Score 10% Verified profile, ratings, completed deals
Output:
  • Match score displayed as percentage (e.g., 87% Match)
  • Top 20 matches shown on AI Matches screen, refreshed daily
  • New matches trigger push notification
  • User can Accept (Connect) or Skip each match

3.9 Trust Score System

Trust Score is a 0–100 rating that reflects a user's reliability and activity on the platform.

Component Max Points Criteria
Profile Completeness 20 pts All fields filled, photo uploaded, bio added
Verified Phone/Email 15 pts OTP/email verification completed
Deals Closed 25 pts 5 pts per converted deal (max 25)
Peer Ratings 20 pts Average star rating from other users × 4
Activity Frequency 10 pts Logins and posts in last 30 days
No Violations 10 pts No blocks/reports against user
  • Trust Score displayed as a badge on profile
    Bronze: 0–40 Silver: 41–70 Gold: 71–100
  • Low Trust Score users have reduced visibility in AI Matches
